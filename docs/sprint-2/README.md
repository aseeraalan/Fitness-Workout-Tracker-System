# Sprint 2 course documentation

This folder holds CPS714 Sprint 2 planning, tracking, and review artifacts for the Fitness and Workout Tracker System.

**Scope note:** The repository did not contain an agreed Sprint 2 backlog. The selected work is the **proposed** workout-logging scope from the Sprint 2 brief (authenticated users create, view, edit, and delete their own workout logs), plus the required course documentation.
